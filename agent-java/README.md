# State-Driven Agent — Java

The Java server is a standalone Spring Boot WebFlux application. It loads the same immutable YAML workflow profiles as `agent-python`, drives the same workflow/evidence state machine, calls OpenAI-compatible chat-completions model services, and executes the shared PostgreSQL fixture tools. PostgreSQL stores both JSONB state/config snapshots and the append-only event ledger before every streamed event is exposed.

```sh
cd agent-java
mvn spring-boot:run
mvn clean verify
java -jar target/agent-java-0.2.0.jar
```

Set `AGENT_CONFIG_ROOT`, `AGENT_SESSION_R2DBC_URL`, `AGENT_SESSION_DB_USER`, `AGENT_SESSION_DB_PASSWORD`, `OPENAI_BASE_URL`, `OPENAI_API_KEY`, and `MAIN_MODEL` as appropriate. API paths match [`../agent-go/openapi.yaml`](../agent-go/openapi.yaml). The database must contain the fixture tables generated by `agent-python/scripts/generate_fixtures.py`.
